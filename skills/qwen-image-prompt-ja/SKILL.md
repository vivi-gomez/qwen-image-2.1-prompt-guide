# Qwen-Image-2.1 プロンプトガイド（日本語版）

Qwen-Image-2.1（2026-09-20公開）は7Bの統一モデルです。テキストからの生成、画像編集、複数参照画像の合成、透明（RGBA）出力、業界最高水準のテキストレンダリングをネイティブ2K解像度でこなします。プロンプトは**流暢な自然文**で書きます。Stable Diffusion式のタグ羅列は使いません。

## 常に適用する基本ルール

1. **自然文で書く。タグ羅列は禁止。** Qwen画像モデルはSD式タグや `(term:1.5)` の重み付け構文を無視します。強調は描写で行います（"with vibrant, striking red hair"）。
2. **描写プロンプトは英語で出力する。** ユーザーが日本語で依頼しても、モデルに渡す説明文は英語に書き直します。*画像内に描く文字*だけ元のスクリプトのまま（日本語は日本語、中国語は中国語）。
3. **被写体を文頭に置く。** このTransformerは早く出てくる具体的なトークンを重く見ます。被写体 → 環境 → スタイル → 構図 → ライティングの順。
4. **画像内に描く文字列は二重引用符に入れて一字一句そのまま。** `a neon sign that reads "GRAND OPENING"`。大文字小文字・句読点は書いた通りに再現されます。
5. **編集プロンプトは「編集内容＋保持宣言」をセットで。** "Change X to Y. Keep everything else unchanged."（XをYに変える。他はすべてそのまま）。1回の編集には1つの論理的な変更のみ。大きな変更は小さい編集の連鎖に分割します。
6. **アスペクト比・解像度はパラメータで渡す。** プロンプト文中に "16:9" や "4K" とは書きません（`wh_ratio`、`size`、UIの比率指定を使う）。
7. **品質ブースターを使わない。** "masterpiece", "8K", "highly detailed", "award-winning" は2.1で公式に非推奨です。代わりに見えるものを描写します。

## ルーティング

| ユーザーの目的 | 書く前に読むファイル |
|---|---|
| テキストから新しい画像を生成 | `references/text-to-image.md` |
| 既存画像の修正・スタイル変更・合成 | `references/image-editing.md` |
| 画像内に読める文字を描く（ポスター・看板・UI・チャート） | `references/text-rendering.md`（＋生成または編集のページ） |
| 透明PNG・ステッカー・被写体切り抜き | `references/capabilities.md` の「透明画像」 |
| アスペクト比、ネガティブプロンプト、CFG、シード、ステップ数、実行方法 | `references/capabilities.md` |
| 実際に動くと分かっているプロンプト例 | `references/examples.md` |

## 進め方

1. モードを判定する: **生成**、**編集**、**合成**。画像内に読める文字が関わるなら、モードのルールに加えてtext-renderingのルールを重ねます。
2. 対応するreferenceファイルを読む。記憶だけで書かないこと — 公式のスタイル規則は詳細で、直感に反する部分があります（レイアウトには長い観察描写、編集には保持宣言、など）。
3. プロンプトを英語で起草し、上の基本ルールと照合する。
4. アスペクト比を意味から選び（縦物→2:3、プレゼン→16:9、バッジ・アイコン→1:1）、パラメータで渡す。デフォルトは横物3:2・縦物2:3。
5. 失敗報告（文字化け、被写体違い、顔のドリフト）があったら、書き直す前に `references/capabilities.md` の失敗パターン表を確認する。

## 最小テンプレート

```text
シンプルな生成:
A neon shop sign that reads "QWEN IMAGE 2.1", rainy night, reflections on wet pavement

シンプルな編集:
Change the background to a sunset beach. Keep the subject, pose, and lighting unchanged.

透明ステッカー:
This is an RGBA image with transparency. A cute cartoon dragon sticker.
The image has alpha channel and the background is transparent.
```

要素が多い場面、位置の指定が細かい場面、複数のテキストブロックがある場面では、`references/text-to-image.md` のロングフォーム形式に切り替えてください。短いプロンプトはレイアウト系・ポスター系で性能が出ません。

## 日本語を扱うときの注意

- 依頼は日本語で受けて構いませんが、**モデルへの説明文は必ず英語に翻訳してから渡します**（公式仕様）。画像内に描く日本語の文字列だけ、日本語のまま引用符に入れます。
- **日本語文字の直接生成（T2I）は崩れやすい**のがこのモデルの既知の弱点です。対策は `references/text-rendering.md` の「日本語テキスト」節を参照してください（編集モードで「忠実になぞる」方式が定石）。
